# Proyecto

## Dead Harvest *(Nombre provisional)*

### Descripción

**Dead Harvest** es un videojuego de acción, supervivencia y roguelite en 2D con perspectiva **Top-Down**, desarrollado como proyecto integrador del curso Ingeniería de Software II.

El jugador deberá sobrevivir a oleadas progresivas de zombis utilizando únicamente armas cuerpo a cuerpo, administrando recursos como la vida y la estamina mientras enfrenta enemigos con distintos comportamientos controlados mediante inteligencia artificial. Durante la partida podrá obtener mejoras temporales, utilizar diferentes armas y enfrentarse a un jefe final para escapar de la zona de cuarentena.

---

## Objetivo del proyecto

Desarrollar un videojuego funcional en un período de **20 semanas**, aplicando los principios de Ingeniería de Software mediante la elaboración de una Especificación de Requisitos de Software (ERS), Product Backlog, historias de usuario, diagramas UML, arquitectura del sistema y un proceso de desarrollo basado en metodologías ágiles.

El proyecto busca integrar las buenas prácticas de análisis, diseño, documentación, control de versiones y desarrollo colaborativo utilizando Unity 2D como motor principal.

# Organización del proyecto

El desarrollo del videojuego se administra mediante **GitHub Projects**, siguiendo una metodología de trabajo basada en Scrum.

La planificación se organiza mediante:

- Product Backlog
- Sprint Backlog
- Historias de Usuario (HU)
- Requerimientos Funcionales (RF)
- Requerimientos No Funcionales (RNF)
- Casos de Uso (CU)

Cada historia de usuario mantiene trazabilidad con los requerimientos definidos en la ERS, permitiendo que la documentación y el desarrollo permanezcan sincronizados durante todo el ciclo de vida del proyecto.
